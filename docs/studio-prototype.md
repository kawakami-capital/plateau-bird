# 京都駅周辺・制作ツールの試作

更新：2026年11月11日（日本時間）。他9都市へは適用していません。

## 内容

- 住所を国土地理院の公開検索へ送信し、候補を表示。候補の代表点が収録建物の座標範囲内の場合だけ、その上空へ移動します。入力前に外部送信と代表点の注意を表示。座標変換は小範囲の近似で、敷地・番地精度は保証しません。
- 現在の視点を開始と終了として保存し、その間を飛行する3D動画を端末内でMP4化します。既存AI外観を使用し、新規AI動画生成や有料APIは呼びません。WebCodecs/AVC対応が必要で、非対応なら理由を表示します。Mediabunnyを同梱ビルドし、外部CDNは使いません。
- クリックした地面へ仮の箱を置き、階数×3.5mと幅・奥行を反映します。既存建物は削除しません。窓は手続き描画で、新規AI外観生成ではありません。
- 2560×1440の画像と動画へイメージ・非実測・実在計画ではない旨と出典を焼き込みます。
- 高精細表示は表示画素数を最大2倍、上限500万画素にする描画設定です。原画1024pxにない細部をAIで復元したとは案内しません。

## 安全と制約

CSPの追加先は `https://msearch.gsi.go.jp/address-search/AddressSearch` だけです。blob/data、HTML非保存、ハッシュ資産の長期保存を維持します。APIは提供継続・仕様・番地精度を保証しません。過剰な自動取得をせず、利用者の送信時だけ問い合わせます。

仮の建物は実在計画ではなく、法規・権利・敷地・日影・構造・建築可否は未検証です。

実ブラウザでの描画・MP4出力・操作性は別途確認が必要です。DOMや算術の単体テスト、HTTP200・ハッシュ一致だけで動作確認済みとはしません。

## テスト

`npm ci --ignore-scripts`、`npm run test:viewer`、`npm run test:studio`。

新規AI超解像・生成モデルは既存環境に見つからなかったため導入していません。比較画像に使う2倍出力はLanczos拡大と輪郭調整で、AI超解像ではありません。Macの試作動画は既存AI画像の深度点群から作る再投影で、WebGL実画面の録画ではありません。
