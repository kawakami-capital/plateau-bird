# 制作パネルの折りたたみ

京都駅周辺の「行きたい建物へ／制作ツール」はページを開くたびに閉じた状態から開始します。画面端の「🔧 制作ツール」で開閉でき、閉じるボタンとEscでも閉じられます。開いたときは自由飛行を終了します。

スマホ（幅760px以下）では下から出る非モーダルのシートです。地図を覆うのは開いている間だけで、最大65dvh。地図クリックによる建物配置を続けられるよう、背景操作を禁止するモーダルにはしていません。

選択した建物情報はこの領域内だけで表示し、建物を選んだだけではパネルを開きません。住所検索・AI外観・動画・仮建物・画像保存の内容は維持。画像動画書き出し中はEscでパネルを閉じず、中止ボタンへアクセスできるようにしています。

`npm run test:panel`はDOMと統合箇所の検査です。実ブラウザと実スマホの表示・操作は別途確認が必要です。
