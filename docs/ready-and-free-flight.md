# 受付前表示・自由飛行・情報欄整理（2026-11-11 JST）

- 都市選択横に常設「＋ エリアを追加」。ドロップダウン内の項目も維持。候補と価格は案内を初めて開くときだけ取得。
- 支援案内の上部に固定した黄色の準備中帯。支援ボタンはdisabledで、Stripeへのリンクは作らない。設定JSONにテストURLが残っていても使用しない。本番決済なし。
- 鳥ボタンで自由飛行。WASD/矢印で水平移動、Q上昇/E下降、地図ドラッグで向きを変更。スマホは操作パネルの方向ボタン長押し。速度10〜120m/秒。
- 鳥ボタン再押下またはEscで通常操作へ。検索・既存の自動周遊・画像動画保存などへ切り替える際も終了。キー入力中の文字入力、非表示タブ、フォーカス離脱に配慮。
- 衝突補助は建物外接箱を8m膨張させた線分判定と壁沿い移動。高さ12〜1200m、注視点から水平±1800m。仮建物も対象。精密な衝突防止ではなく、実測・樹木・細い部材・AI画像で描かれた形状を保証しない。
- 左下の長い表記をⓘへ集約。隅には「出典：PLATEAU／国土地理院」だけ残し、既存出典ダイアログへMIT条件・公開試作注記・note販売予定を一度ずつ掲載。保存画像と動画の出典注記は削除しない。
- `npm run test:viewer`、`npm run test:studio`、`npm run test:flight`でDOM・操作ロジックを検査。これはWebGLや実ブラウザ・実機確認の代わりではない。
