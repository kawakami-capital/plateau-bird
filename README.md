# 街を、とぶ。 — PLATEAU 鳥視点マップ

国土交通省 Project PLATEAU の外観つき3D都市モデル（CityGML LOD2）を GLB に変換し、ブラウザーで鳥の目から眺めるためのオープンソースです。閲覧の仕組み、変換の手順、制作支援プランの試作画面を、出典を付けて誰でもコピーして使えるようにします。

合同会社Kawakami Capital Research & Partners が整えている一式です。プログラムは MIT ライセンスで、誰でもコピーして利用できます。公開リポジトリは https://github.com/kawakami-capital/plateau-bird です。完成した街の公開配備や、決済の開始とは別です。

完成した街は、公開の承認後、誰でも見られ、プログラムは MIT、変換データは出典つきの CC BY 4.0 で使えるようにする方針です。現況の正確さや、生成AI映像のような写実性を保証するものではありません。日照・採光・眺望や物件の判断には使わないでください。

## リポジトリの構成

```
viewer/                 鳥視点の Three.js ビューア（操作ガイドつき）
viewer-mesh/            変換直後のメッシュを確認する簡易ビュー
pipeline/tools/         CityGML LOD2（外観つき）→ GLB の変換
pipeline/catalog/       都市カタログ（10都市の例、東京23区）
worker/                 Cloudflare R2 の手前に置く配信 Worker（未配備）
scripts/                ローカル確認、R2アップロードの準備脚本
support-plan/           制作支援プランの試作画面（決済なしでも閲覧可）
```

大きな GLB、結合した航空写真、制作支援プラン用の町丁境界（GeoJSON と一覧）は入れていません。変換と地面の生成、または `support-plan/data/README.md` の手順で用意する想定です。生の AI 画像も入れていません。

## ローカルで動かす

必要なもの: Python 3.12 相当、およびビューア確認用のブラウザー。変換には `pipeline/requirements.txt` のパッケージ（requests、remotezip、lxml、numpy、pyproj、Pillow、mapbox-earcut）を使います。追加のアカウントや API キーは不要です。

```bash
# リポジトリのルートで、このマシンだけに向けて開く
./scripts/serve-local.sh
```

- 鳥視点: http://127.0.0.1:8771/viewer/
- 制作支援プランの試作: http://127.0.0.1:8771/support-plan/

同梱の `viewer/cities.json` は書き方の例だけです。変換済みの GLB と地面画像がないと、街並みは読み込めません。`file://` ではデータが読めないことがあります。外部から届く待受（0.0.0.0）は、この脚本では使いません。

## 新しい都市を変換する

1. 対象都市の CityGML が、[PLATEAU](https://www.mlit.go.jp/plateau/) / [G空間情報センター](https://www.geospatial.jp/) で公開されているか、同梱 README の個別条件を確認します。
2. カタログに都市を追加します。`pipeline/catalog/cities10.json` の形（市区町村コード、名前、年度、catalog_url、zip_url、origin の緯度経度、必要なら meshes）を参考にしてください。東京23区は `tokyo23.json` もあります。
3. 仮想環境を用意し、必要なメッシュだけを変換します。

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r pipeline/requirements.txt

# まず目録だけ見る
.venv/bin/python pipeline/tools/pipeline.py --catalog cities10.json --city 26100 --list-only

# 小さな範囲で変換（例: 京都駅周辺の2メッシュ）
.venv/bin/python pipeline/tools/pipeline.py --catalog cities10.json --city 26100 --meshes 52353680 52353670 --root ~/plateau-map

# 変換結果からマニフェストと cities.json を書く
.venv/bin/python pipeline/tools/prepare_viewer.py --root ~/plateau-map --viewer-dir ./viewer
```

`--origin` を省略すると、カタログの `origin` を使います。安全のため、空き容量が 30GB を下回る見込みなら停止します。既定では都市全体の ZIP を保存せず、必要なメッシュと画像だけを公式の配布元（`assets.cms.plateau.reearth.io`）から部分取得します。成功後、一時原典は削除します。

4. 地面の航空写真を作ります（地理院タイル「全国最新写真」）。出典と加工の記載が必要です。対象タイルに追加の出所明示がないかは、[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html) で確認してください。

```bash
.venv/bin/python pipeline/tools/prepare_ground.py --code 26100 --lat 34.986 --lon 135.759 --outdir ./viewer
```

生成される `viewer/ground/26100/aerial.jpg` は `.gitignore` の対象です。リポジトリには入れないでください。

5. `viewer/cities.json` の `manifest` と `ground` が、変換結果と地面の相対パスを指していることを確認し、ローカルの HTTP サーバーで開きます。

画像は長辺 512 画素以下に縮小してからアトラス化するため、外観の細部は原典より粗くなります。LOD2 が無い棟は LOD1 の単色を代用します。GML の座標系は確認して処理し、想定外なら誤変換せず停止します。

## Cloudflare R2 と Worker で配置する

公開の承認があるまで、`wrangler deploy` は実行しないでください。誤って実行しても即時の公開 URL を作らないよう、`workers_dev` は false にしてあります。それでもアカウントには Worker が置かれることがあるため、承認前は配備しないでください。

方針の概要:

1. R2 バケットを作り、当初は公開アクセスを付けません。
2. ビューアの静的ファイルと、変換した GLB・地面画像・マニフェストをバケットへ置きます。認証情報はファイルに書かず、環境変数（`CLOUDFLARE_ACCOUNT_ID` や API トークン）を使います。`.env.example` を参考にしてください。`scripts/upload-to-r2.mjs` は準備用で、送信はしません。
3. `worker/` の Worker 経由で配信します。バケットを直接インターネットへ公開するのではなく、この Worker がファイルを返す想定です。
4. 独自ドメインは、ゾーンの追加と公開の承認後に付けます。
5. 公開後も、画面と保存画像に PLATEAU と地理院タイルの出典を残します。

費用の目安（公式、2026年11月11日確認）: R2 のインターネット向け転送料はありません。保管は標準で 1GB・月 0.015 ドルなど。無料枠や Workers の有料プランの条件は、Cloudflare の料金ページで確認してください。この文書の数字は見積もりの参考であり、契約を保証しません。

## 制作支援の仕組み

`support-plan/` は、市・区・町名・丁目（条丁目を含む）を選ぶと金額が変わる試作画面です。これは寄付ではありません。制作を依頼し、できた街は誰でも見られ、プログラムと変換データは出典つきで公開する、有料の支援プランです。

- お客さまには税別の金額（または個別見積もり）、棟数、品質ランク、外観の注意を出します。
- 内部用のチェックを入れると、売上・費用・利益の内訳を見られます。目標は、決済手数料 3.6% を引いたあとで利益率 50% です。下限（税別 16,000 円）を適用する小さな範囲では、利益率は 50% を超えます。区全体・市全体や未実測の広い範囲は個別見積もりです。
- 支援してくださった方のお名前は、本人が希望し、表示名を指定した場合だけ掲載します。既定は匿名です。
- 街が完成したら、希望された方へメールでお知らせする案です。この試作からはメールを送りません。
- 決済は Stripe を予定しています。このリポジトリには、アカウントや決済リンクの識別子を入れていません。`support-plan/data/stripe-test.example.json` が書き方の例です。

作業時間や AI の単価は推定です。実際に1件作ってから見直す前提です。特商法の表示は下書きで、「要確認」の項目があります。
